Ajouter une date d’inventairePlanifier le prochain inventaire.

Importer plusieurs événementsImporter un tableau ou fichier CSV.

Utilise un fichier CSV exporté d’Excel ou de Numbers, ou colle directement un tableau avec les colonnes type ; code ; titre ; debut ; fin. Les dates au format JJ/MM/AAAA sont acceptées.

Comment préparer mon tableau ?

1. Ouvre Excel ou Numbers et crée cinq colonnes dans cet ordre : type, code, titre, debut, fin.

2. Ajoute une ligne par événement. Pour un inventaire, écris inventaire dans « type » et renseigne uniquement « debut ». Pour une opération commerciale, écris evenement et renseigne son titre et sa date de début.

3. Utilise les dates au format JJ/MM/AAAA ou AAAA-MM-JJ. La date de fin et le code sont facultatifs.

4. Exporte ton tableau au format CSV, puis sélectionne le fichier ici. Tu peux aussi copier les lignes du tableau et les coller directement dans la zone ci-dessous.

5. Appuie sur Vérifier le tableau, contrôle l'aperçu puis sur Confirmer l’importation.

Exemple à copier
type;code;titre;debut;fin
evenement;27P15;Opération fruits et légumes;08/02/2027;14/02/2027
inventaire;;;15/02/2027;

Conseil : conserve ton fichier CSV pour pouvoir le compléter lors du prochain planning. Un événement déjà identifié par son code est mis à jour plutôt que dupliqué.
