V31.26 — Espaces indépendants. Le mode invité conserve ses données locales. Chaque compte Supabase possède sa propre copie locale. Lors de la première connexion à un compte cloud vide, une copie des données invitées est importée. Une déconnexion ramène à l’espace invité. Attention : les comptes Google et e-mail que Supabase lie à un même user_id ne sont pas séparés par cette version. La synchronisation concurrente sur plusieurs appareils reste limitée.
