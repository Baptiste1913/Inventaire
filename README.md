# Mettre à jour Inventaires U — V27.4

1. Avant toute mise à jour, ouvrir **Réglages et données** et **Exporter toutes mes données (JSON)** pour conserver une sauvegarde.
2. Décompresser le ZIP et remplacer **tous les fichiers à la racine** du dépôt GitHub Pages.
3. Faire **Commit changes** et attendre le déploiement.
4. Ouvrir `inventaires-u.com` avec Internet, recharger une fois puis rouvrir l’application depuis l’écran d’accueil.
5. Vérifier le nouveau bloc **Réglage de la pesée** et le bouton **Démarrer un inventaire**.

## Changements V27.4

- Bloc **Réglage de la pesée** déplacé juste sous **SERVICES U / CALCUL**, avant **Type de panier**.
- Présentation plus claire et plus compréhensible du choix entre **saisie classique** et **saisie rapide sans virgule**.
- Design volontairement discret pour rester lisible sans alourdir la carte de calcul.
- Icône du bouton **Démarrer un inventaire** remplacée par la nouvelle icône fournie, affichée en blanc.
- Cache hors ligne mis à jour pour inclure ce nouveau visuel et les nouveaux styles.

## Installer cette version

Remplacer les fichiers du dépôt GitHub Pages par ceux de cette archive. Ouvrir une première fois le site avec Internet pour mettre à jour le cache de l’application hors ligne.
